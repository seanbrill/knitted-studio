# Projects

A project holds everything for one brand or campaign: one Swatch, your Yarn, and the Patterns you have built from them.

## What a project is

A project is a plain folder on your computer. You can open it, copy it and back it up like any other folder. Nothing is hidden in a cloud account.

## Several brands

You can keep as many projects as you like. Each has its own Swatch, so a post for one brand can never pick up the colours of another.

## Today

Your model can list your projects with the `list_projects` tool. Creating and switching projects in the studio is on the way.
