# Yarn

Yarn is your raw material. Photos, logos, video, audio, fonts and pieces of copy are all Yarn.

## Where it lives

Yarn belongs to a project. Each file is stored in the project folder and addressed by name, so a Pattern can ask for "the hero photo" and keep working when you swap the file.

## Folders

Sort Yarn into folders, like a folder for royalty free music with one inside it for each kind. Upload into a folder by opening it first. See [Folders](/docs/folders/).

## Good Yarn

- Upload logos at least 1000 pixels wide so they print sharp.
- Use photos you have the rights to. See [Brand and legal guidance](/docs/brand-and-legal/).
- Give files plain names. Your model reads them.

## Your model

Your model adds Yarn from a public web address, or from a file on your computer by its path, and saves pieces of text as copy. It copies a file in and leaves yours as it was. It does not read hidden folders or files, such as ~/.ssh. It can bring a piece of copy up to date, such as a note on how a job is going, instead of saving a second one beside it. The project's Activity shows each file it adds and each piece of copy it changes. It cannot delete Yarn.
